## Remaining high-priority finding: not all binding forms/scopes are handled

### Python exception binding is omitted

The builder accepts this function and selects `token`:

```python
def f():
    token = 1
    try:
        raise ValueError(7)
    except ValueError as token:
        return token
```

The generated probe renames the initial assignment and return to `token_renamed`, leaving
`except ValueError as token` untouched. Original execution returns a **ValueError object with
message 7**; the probe returns **integer 1**. Both parse and the builder's isomorphism check passes.
`ExceptHandler.name` is not an `ast.Name`, so name-node replacement omits a real binding site.
This failure occurs inside a single function; excluding nested functions/comprehensions does not
address it. It also affects the patched path when the same source is provided there.

### JavaScript default argument is in a different scope

With global `token=10`, the builder accepts:

```javascript
function f(x=token) { let token=1; return x+token; }
```

It renames both the default argument's global reference and the body-local declaration:

```javascript
function f(x=token_renamed) { let token_renamed=1; return x+token_renamed; }
```

Original `f()` returns **11**; the probe throws **ReferenceError**. The signature-scope correction
was added for Python, but the tree-sitter path still performs same-spelling replacements across
the function signature and body. This was executed with Node, not inferred from tree shape.

Both full input/output pairs are retained in `Dev_Probe_Round3_Evidence_20261013.json` and
asserted by `audit_dev_probe_round3_20261013.py`. No network, inference or Semgrep execution is
needed for the reproductions.

## Recommended resolution and scope

The individually reported fixes work; the claim that the whole lexical-binding problem is closed
is still too broad. Treat these as one remaining root issue. Use declaration/reference resolution,
or explicitly limit accepted syntax to supported binding forms and reject candidates affected by
any unhandled form. A parser/isomorphism test cannot substitute for that binding contract.
Add runtime regressions for both cases on vulnerable and patched sides; inspect language-specific
signature and binding positions systematically instead of assuming all names are ordinary loads
or stores. The validated-source fallback fix remains closed for the previously reported inputs.

No reason has emerged to change historical E2E numbers or rerun model inference. Preserve the
deferred status of C/D, and do not equate passing the builder suite with tested repair-loop gating.
